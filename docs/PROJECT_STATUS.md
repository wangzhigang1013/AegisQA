# AegisQA 项目记忆

## 当前阶段
已进入稳定运行与功能拓展期。已实现 RBAC 权限控制、前端多页面路由与模块化管理、技能生命周期管理（支持打包与版本控制）、合规与安全审查等。

## 最近改动 (弹窗层级与路由过渡架构级重构)
- **废弃 SetTimeout 延迟魔法**：响应用户的直觉反馈，移除了之前在跳转逻辑中引入的 300ms 强制延迟。
- **引入 usePresence 绝对安全销毁机制**：重写了底层的 Modal 组件，接入了 framer-motion 提供的 usePresence Hook。现在，当 React 发生路由切换并触发父级页面的“缓出动画”时，底层 Modal 能够瞬间感知到并立即返回 null。这从架构层面上绝对彻底杜绝了路由切换时由于旧 DOM 被冻结导致跨页面出现“幽灵双弹窗”的问题。
- **2026-06-23**: 
  - 修复全局 Modal (基于 createPortal) 导致 framer-motion 卸载死锁白屏的重大 Bug。
  - 修复 SkillsPage 的 URL 参数防抖设计，解决二次弹窗。
  - 清除 SkillApprovalDrawer 等组件内部的冗余嵌套 max-h 和 overflow 解决多重滚动条问题。
  - 修复 RunsPage 的 URL 参数与本地 state 竞态防抖漏洞，彻底消除“执行记录”页面的抽屉双重回弹问题。
  - 彻底修复 `TraceFlowPage` 等页面由于 `item_id` 状态不一致或重复导致的侧边栏无法高亮选中的样式 BUG，现已采用基于 `Index` 的稳定状态锁定。
  - 撤回 WorkflowDesignerPage 的强制 Dagre 排版，防止旧节点被强制重新编排。
  - **(新)** 修复 App.tsx 全局布局边距（padding）挤压了 WorkflowDesignerPage，并将画板容器从硬编码的 `w-screen h-screen` 修正为弹性的 `w-full flex-1`。同时，为全局最外层容器 `App.tsx` 动态赋予了 `h-screen overflow-hidden`，并为左右侧边栏（Skill Palette 和 Inspector）增加了 `min-h-0`。这彻底解决了画板高度超出屏幕引发滚动条、导致底部的 Minimap 被挤到屏幕下方的问题。现在，整个页面被死死锁定在 100% 屏幕大小内绝不滚动，而左右侧边栏可以在自己的区域内**独立滚动**。
  - **(新)** 破除了 WorkflowInspectorPanel 内部错误的多重嵌套滚动条结界。现在连线、参数、校验结果不再互相挤压在一个微小的固定高度容器内，而是作为统一的瀑布流自然向下延伸，只需一次滚动即可丝滑浏览全部配置项。
  - **(新)** 优化了底部 `WorkflowConsolePanel`（校验与试运行面板）的可用空间：我发现它之前被错误地嵌套在了极其狭窄的右侧 360px 的 Inspector 边栏最底部，导致它不仅自己被挤压到无法看清 JSON，还让原本可以用来展示配置项的右侧边栏下方留下了一大片死白空间。现在我已经**将它彻底从右侧边栏中拔出，安放在了中间 Canvas 画布区域的正下方**！这一史诗级改动让 Console 获得了超过 1000 多像素的超级宽幅横向空间，并且将其基础高度提升至 320px。现在 JSON 代码块有了极其宽敞的展示舞台，而右侧的节点配置面板也重获了贯穿整个屏幕的完整高度！
  - **(新)** 彻底修正了全局 `Card.tsx` 组件的设计基准。将 Shadcn UI 默认自带的极其浪费空间的 `p-8`（32px）全局内边距直接砍到了 `p-4`（16px）。这让整个项目（包括底部的 Console 和所有的弹窗侧边栏）瞬间获得了高密度、紧凑的“专业 IDE 级”展示面积，不再需要我们在每个页面里手动去覆盖 padding！
  - **(新)** 修复了 ReactFlow 的初始视野缩放策略。通过限制 `maxZoom: 1` 阻止了因为初始节点过少而导致画板强行放大 300% (`scale(3)`) 的暴走缩放，同时对内部所有节点的 CSS 组件进行了等比缩放压缩 (缩小了宽高、字号和间距)，极大地提高了屏幕利用率。
  - **(前端)** 全面重构了中间画布区域节点的 UI 视觉 (`BaseNode.tsx` & `BaseNode.css`)：移除了顶部厚重的彩色渐变块 (`decor`) 以实现更极简的高级感；修复了之前由于 `\n` 导致标题被重复换行显示的问题，将节点标题（Label）与副标题（节点类型/引用名）正确分离；重设了整个节点的柔和边框、内边距、弥散阴影和鼠标悬浮/选中态的高亮光晕。
  - **(前端)** 重新设计了工作流连线与端点逻辑：彻底移除了节点上每个字段独立携带的小圆点端点（Handle），改为在节点左右侧只保留单一全局输入/输出端点，大幅减少视觉噪音；为所有连线默认开启了 `animated: true` 流动动画与加粗描边，使数据流向一目了然；并在 `onConnect` 阶段加入了严谨的 DAG 防环逻辑，严格禁止节点之间的“互相死锁双向连线”和“自我连接”。
